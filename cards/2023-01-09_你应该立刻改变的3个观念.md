# 你应该立刻改变的3个观念

**一句话**：过去二十年被当成「向来如此」的三件事——公务员吃香、房价只涨、阶层固化——都只是一个时代的红利；衰退期恰恰是阶层调换期，要在精力最好的几年拼到极致去抓新机会。

**论证链**
1. 公务员靠财政供养，经济差、税收和土地出让金少了，高收入就没有来源。它会不错，但不会再那么好。
2. 体制里有些没能力的领导，只是在没人愿意进体制时进去、后来吃到了红利。人没变，变的是赛道。
3. 房价二十年上涨的本质是供需：商品房放开加农民进城造成短期失衡。传统观念、丈母娘经济是结果不是原因。现在供给过剩、人口和购买力下滑，没有支撑高房价的因素。
4. 补贴变相降价、挂牌价却维持高位，让持有者误以为房子还值那个价。政策带来的短期回暖，可能是最后的逃生窗口。
5. 阶层固化只出现在平稳期。现代社会大约每十年一次大衰退，随后孵化技术革命；衰退期放水稀释存量，同时让赚新钱的人拿到最多。
6. 一生能全力工作的时间有限，错过三次十年一遇的机会，就基本定型了。所以在动荡期加倍学习和尝试新方向，而不是一直拼。

**可复用的模型**
- **把红利误当常态**：某个选项过去十几年好，先问它靠什么好，那个条件还在不在。
- **供需优先**：分析资产价格先看供需，其余解释多半是因果倒置。
- **衰退期 = 阶层调换期**：存量被稀释、增量机会集中出现的时候最容易换位置。
- **集中拼**：没人能一直拼，把力气集中在性价比最高的几年。

**可调用的场景**：考虑考公、买房或卖房时；抱怨阶层固化、觉得经济下行没机会时；规划未来几年精力投入时。

**原文锚句**：「在最有性价比的几年拼到极致，这才是聪明人的选择。」

**使用边界**（整理者注，不是作者观点）
- 公务员降薪、房价走势、「每十年一次大衰退」都是 2023 年初的判断和预测，引用时要结合之后的实际数据核实。
- 「人家干12小时，你得干16小时」是作者的激励说法，针对的是机会窗口期，不是长期作息建议。
