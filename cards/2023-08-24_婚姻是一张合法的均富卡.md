# 婚姻是一张合法的均富卡

**一句话**：婚姻把原本可以明码标价买到或租到的服务，用说不清的权利义务和永远五五分的「股份」搅在一起，相当于大富翁里的均富卡，且掌握在穷的一方手里；一次性交出全部筹码换来的关系不可持续，长期关系靠的是长期有给付的预期。

**论证链**
1. 引子是一则争议新闻：相亲订婚后，女方家要求立刻加名、付清彩礼，未办到就报了强奸案，男方被拘。作者看过采访后倾向认为男方被人设计，但也说是否存在强奸不好说。
2. 作者认为婚姻提供了一次可以明抢的机会；这份「20 万 + 半套房换一年权利义务」的协议不配叫「彩」礼。
3. 这种协议常见的结局是对方在一年后带钱离开。要花这么多钱才能在一起，说明你们本来就不匹配；钱付完、没有后续补贴，关系无法维系。
4. 一次性拿出所有东西就能维持长期关系，是幻觉；长期关系靠长期有给付的预期，一次交付完就失去了筹码。
5. 认知最贵：不修认知，认知会在方方面面修理你。
6. 结婚的硬性理由（户口等）已陆续被法律取消；物质丰沛、孩子有保障时，婚姻越来越没必要。
7. 正常交易明码标价、有期限，婚姻没有价格、没有期限、贡献难衡量，像永远五五分的合伙；贡献大的一方也不能多拿，合伙早该散了。

**可复用的模型**
- **均富卡**：婚姻的财产平分机制对贡献少的一方有利。
- **长期给付预期**：维系关系的是未来的持续价值，不是一次性付出。
- **五五分是最烂的股份比例**：贡献变化时无法调整的合作难以持续。
- **明码标价更清晰**：能用价格解决的需求，用价格解决。

**可调用的场景**：谈婚论嫁、谈彩礼和加名时；想通过一次性大投入挽留关系时；评估婚姻的成本收益时。

**原文锚句**：「长期的关系，靠的是长期有给付的预期」

**使用边界**（整理者注，不是作者观点）
- 引子是当时正在审理的刑事案件，作者对真相的判断是基于采访的推测，不能当作事实；涉及性侵指控的案件应以司法结论为准。
- 作者对女方的定性（「买人钱」「嫖资」）措辞激烈，属个人评价。
- 「婚姻会越来越没必要」是作者的预测；婚姻法中的财产规则比「五五分」复杂，具体以法律为准。
