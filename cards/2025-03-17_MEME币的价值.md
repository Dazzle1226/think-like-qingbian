# MEME币的价值

**一句话**：作者认为，价值不需要官方认定，本质是「有多少人想要、愿意出更高的价格接手」。所有投资品都用同一个标准判断：共识有多大、有多稳定、能不能持续吸引新人。股票更稳，是因为业绩让共识更稳定，这就是护城河；大多数 MEME 币失败，是因为共识太小、太短，而不是因为它是 MEME 币。

**论证链**
1. 很多人说 MEME 币是空气币、传销币；官方也只认定少数主流币是资产。作者认为，需要盖章认定才算有价值，说明不懂价值。
2. 作者以自己收藏的 NFT 为例：对不感兴趣的人一文不值，对想要的人就值那个价。关键在于想要的人有多少，不想要的人是讨厌还是无感，没有区别。
3. 只要东西有限、想要的人多，就有投资价值，因为投资价值的本质是下一个人愿意出更高的价格买走它。
4. 精神需求和身份认同也是真实的需求，不能用自己的温饱状态去推断别人的需求是伪需求，否则奢侈品溢价就不该存在。
5. 99% 的 MEME 币没价值，是因为共识的人太少、进不了新人、持续时间太短。股票也一样：假如某饮料被证实致癌，股价也会暴跌，因为支撑共识的业绩没了。
6. 判断标准：东西本身的特质是什么、共识围绕什么、初始共识有多大、叙事能不能吸引更多新人。公司回购带来上涨、创始人减持带来下跌，都是叙事改变共识的例子。

**可复用的模型**
- **价值等于共识**：有限的东西加上想要的人。
- **投资价值等于下一个更高价的接手者**。
- **护城河等于共识的稳定性**。
- **叙事决定能否吸引新人**。
- **统一标准**：所有资产用同一把尺子衡量。

**可调用的场景**：判断一个新资产、新品牌、新 IP 值不值得投入；理解为什么有些东西「没用」却很贵。

**原文锚句**：「只要东西有限，要的人多，那就有投资价值」

**使用边界**（整理者注）
- 作者身在加密行业，文中关于自身藏品和被盗的说法没有核实过，立场明显。
- 「价值等于共识」是一种视角，忽略了现金流、内在价值等其他估值方法，也容易被用来为击鼓传花式的骗局辩护，使用时要警惕，不构成投资建议。
