# 大多数人都不配有钱

**读者的问题**（只用于理解语境）：一位知名人士留下了大额遗产，女儿年纪还小，这笔钱能守得住吗？是不是只有信托才行？

**作者回答的一句话**：持有多大金额的钱，就要有相应的智慧。一次性拿到超出自己能力的钱，等于多出一大堆犯大错的机会。普通人最好的方式，是用保险或信托定期领钱，用这种机制给自己兜底。

**论证链**
1. 只要不是信托或类似信托的形式，钱到了谁手里都留不住，两代以后大概率被社会均摊掉。
2. 持有金钱需要相应的智慧，就像一个从没带过兵的小卒突然拿到统领十万人的兵符。觉得「存银行就行」「本金到位我就能起飞」的人，真拿到一大笔钱就完了。
3. 定期领钱，给时不时犯浑的头脑兜了底：每一次犯错的最坏后果都被限定住，下个月就能清零重来。犯几十次错，人自然也就学聪明了。
4. 人一定会犯错，巴菲特和芒格到九十多岁都还在犯错。没有兜底机制，每一次犯错的损失都会成倍放大。
5. 爱一个人，就不要一次性给他超出他赚钱能力的钱。给孩子，他未必感恩；给配偶，原本的交换平衡会被打破。
6. 钱必须付出对等的代价才能拿到。代价不够，钱就会以「犯大错」的方式失去，因为多出来的选项、关系和生活方式，都是犯错的机会。

**可复用的模型**
- **持有智慧要和金额匹配**。
- **兜底机制**：限制每一次犯错的最大损失。
- **意外之财会制造犯错的机会**。
- **知道自己驾驭不了，也是一种智慧**：把主导权交给自由度最小的机制。

**可调用的场景**：突然得到一大笔钱（继承、拆迁、奖金）；该给孩子或伴侣多少钱；判断自己能不能驾驭某个金额。

**原文锚句**：「持有任何金额的金钱，都需要有对应的持有智慧」
