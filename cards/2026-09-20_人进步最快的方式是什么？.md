# 人进步最快的方式是什么？

**一句话**：学会任何东西都要走完「教 → 练 → 考 → 纠错」的闭环。大脑是靠对相对值的纠偏来掌握东西的，所以进步最快的环境是高频、多维、失败有严重后果的实战。

**论证链**
1. 学校里「学会」的最小闭环是：老师教；课后练，不会就问；考试排名；整理错题。成绩差多半是闭环缺了某个环节，而不是笨。
2. 离开学校后，闭环缺得更多：看点视频和文章就觉得自己会了，其他步骤一概没有。
3. 大脑掌握一样东西，靠的不是接收绝对值，而是对相对值的纠偏。没有错误和困难作参照，就形成不了概念。
4. 练习、考试、践行、接受市场反馈，都是在从多个维度制造偏差；失败后果越严重，越能逼出专注和投入。
5. 进步慢的人缺的是激烈的竞争、严重的失败后果、高频的实战，以及事后的复盘。没有现成的战场，就自己制造「局部战争」。

**可复用的模型**
- **学会的最小闭环**：教、练、考、纠错，缺一环就学不会。
- **相对值纠偏**：「正确」是在体会过多维度的错误之后才被抓住的。
- **局部战争**：主动给自己制造高频、有后果的检验。

**典型例子**：学生成绩的差异；持续参加综艺和万人演出的歌手，与偶尔露面就显得退步的歌手。

**可调用的场景**：为学新技能做计划；学了很多却没有用；设计练习和反馈机制。

**原文锚句**：「对相对值的纠偏」
