# 你为什么不够自律？看这篇就够了。

**一句话**：不自律是因为放弃小欲望的收益不够直接；自律不是没有欲望，而是和更大的欲望建立了强关联，开始享受靠近它的过程。靠忍受的自律有临界点，靠享受的没有。

**论证链**
1. 如果身材好就给你一千万，你立刻就能自律。不做，是因为收益没有直观到让大脑为「克制」分泌奖赏。
2. 知道健康、有钱有用，但没有真实体验，大脑就无法为抽象的东西奖励你。
3. 作者自己做繁琐的链上任务不痛苦，因为看到了行为和收益的关系，兴奋压过了苦闷；看不到的人只剩苦闷。繁琐门槛本身也挡住了竞争者。
4. 作者从讨厌美式咖啡到非美式不喝：低热量让他觉得在做健康的事，甜味反而让他联想到发胖。当你和更大的欲望强相关时，小欲望就被忽视了。
5. 极度自律背后一定有极度的其他欲望（网帖例子：自律的富有父亲身边追求者不断）。没有异性、没有羡慕，人还会自律吗？
6. 幸福肥是关系稳定的标志，也是危险信号：吸引对方已无法带来奖赏，心动开始流失。
7. 欲望是前进的动力，演员眼里的「杀气」其实是欲望和生命力。

**可复用的模型**
- **收益可见性**：让小行为和大收益之间的联系变得直观，自律就容易。
- **大欲望压制小欲望**：用更强的目标替代对意志力的依赖。
- **忍受有临界点，享受没有**。
- **自律 = 写满欲望**：看一个人的自律，去找他想要什么。

**可调用的场景**：减肥、学习、早起坚持不下去时；想培养一个新习惯时；感情进入平淡期时。

**原文锚句**：「自律不是没有欲望，自律恰恰是写满了欲望。」
