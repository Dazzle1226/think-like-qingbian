# 爱钱不可耻，可耻的是假装不爱钱

**一句话**：所谓含蓄是熟人社会博弈出来的虚伪：凡涉及利益都要套一层大义的壳。直说爱钱比假装不在意更省内耗，投资也一样，带着情绪包装只会让你亏钱还不自知。

**论证链**
1. 长期农耕文明让人很晚才走出熟人社会，面子上的假来假去是熟人社会的生存策略。
2. 涉及利益就套「大义」的壳：红包塞来塞去，谁送少了立刻传遍全村；婚嫁谈判个个精明，却要说成「礼」和「有房才有家」。
3. 颜控可以，拜金就不行，于是喜欢有钱人只能说是喜欢他的性格。
4. 大家都知道彼此怎么想，还非得斗智斗勇，是无意义的内耗。
5. 投资也是：不肯割肉可以承认是人性弱点，但非要说买房爱国、A 股会挺起、比特币是骗局，就是被情绪冲昏了头。
6. 钱最实事求是，赚就是赚，亏就是亏；一切情绪购买都以损失金钱为代价，不会让你既要又要。

**可复用的模型**
- **大义的壳**：识别利益诉求外面包裹的道德说法。
- **直说省内耗**：利益摆上桌面，比互相猜测更高效。
- **情绪购买的代价**：用情绪满足代替理性判断，必然要付钱。

**可调用的场景**：婚嫁、人情往来中谈钱尴尬时；投资亏损后给自己找理由时；识别别人用道德包装的利益要求时。

**原文锚句**：「一切以情感为包装的占便宜，都是耍流氓」

**使用边界**（整理者注）
- 「中国人含蓄是虚伪」是作者的文化判断，带有强烈个人色彩，不是学术结论。
