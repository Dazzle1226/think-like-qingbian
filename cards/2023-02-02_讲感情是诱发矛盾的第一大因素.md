# 讲感情是诱发矛盾的第一大因素

**一句话**：大部分矛盾发生在熟人之间，因为「讲感情」掩盖了对等交易：无法量化的付出让双方都觉得自己给得更多，回报又总是滞后，成本后置让受惠的人反而觉得是你欠他。明码标价、即时回报反而更少矛盾。

**论证链**
1. 跟陌生人打交道不安全，大家守边界，而且用即时回报，所以矛盾少，有了也容易互相迁就。
2. 熟人之间即时回报会被理解为不想再来往，不即时回报又埋下矛盾，尤其在穷人之间。
3. 农村「你帮我我帮你」背后是算计：送一刀肉、回一棵菜，就会被传遍全村。讲感情背后仍是对等交易。
4. 打扫屋子、陪伴这类付出没法量化，各人的标尺不一样，时间长了都觉得自己付出更多。
5. 回报还会错配：拿到帮助时欲望最强、最感激；等到要回报时满足感早已过去，只剩成本，于是觉得是你欠他。就像先收了十年服务费，后面越服务越不情愿。
6. 富人之间有对等交易的共识，明码标价；即便讲感情，彼此对对方的未来资源都有吸引力，不计较一时吃亏。穷人之间缺乏这种吸引力，就更在意当下的盈亏，越走越淡。

**可复用的模型**
- **讲感情 = 不记账的交易**：账没记，不等于不算，只是各算各的。
- **价值量化偏差**：不可量化的付出，双方的标尺不同，必然觉得自己吃亏。
- **成本后置**：先得好处、后付成本的安排，越往后越不情愿。
- **未来吸引力缓冲当下吃亏**：彼此有长期价值的关系，才经得起短期不对等。

**典型例子**：借钱时对方磕头感谢，还钱时却像从自己口袋里掏钱；四个孩子和一个孩子互给红包的难题。

**可调用的场景**：和室友、伴侣、朋友、亲戚之间觉得自己付出更多时；要不要借钱给熟人；设计合作关系的回报方式时。

**原文锚句**：「原因就是成本后置」

**使用边界**（整理者注，不是作者观点）
- 「穷人之间」「富人之间」是作者的概括，带有刻板印象，用时注意语境。
