# 赚钱很简单，才令人绝望

**一句话**：赚钱的原则很简单：找到自己真正懂的逻辑，然后持续做下去。多数人做不到，不是因为执行辛苦，而是因为不懂所以不坚定；看起来核心在「做」，本质在「想」。

**论证链**
1. 芒格持续买苹果，理由是一开始的研究已经足够，之后只做自己能把握的部分，不管短期业绩和股价。
2. 简单的事多数人做不到，原因之一是芒格有无限子弹，更重要的是多数人没找到自己懂的逻辑：不懂 → 不坚定 → 做不下去。
3. 执行的动作从来不是问题，「该不该坚持」的动摇才是。
4. 作者和芒格结论不同（一个囤比特币，一个不喜欢比特币），但都忠于自己懂的部分。不懂可以不买，最多踏空；做多做空都要求你很懂。
5. 你成不了彭于晏不是因为不够自律，而是路径不同：如果练身材能拿一个亿，谁都练得出来。关键是搞懂一件事背后有没有值得长期做的逻辑。
6. 多数人身体上不闲，但思考上闲置着；而收入取决于发现机会、识别机会、做对选择的能力，这需要「想」的努力。
7. 作者少内耗的办法：一有挣扎就想到明白为止，想明白了，「做」反而最简单。

**可复用的模型**
- **懂 → 坚定 → 坚持**：坚持的前提是懂，而不是意志力。
- **能把握 vs 不能把握**：只持续做能把握的部分，其余归为噪音。
- **想先于做**：身体的勤奋代替不了思考的勤奋。

**典型例子**：芒格持续买入苹果；早期巴菲特和芒格说科技股高估值是骗局，后来认错进入；彭于晏的身材。

**可调用的场景**：投资或做事坚持不下去时；怀疑自己不够自律时；觉得自己很努力却回报不高时；内心挣扎、反复内耗时。

**原文锚句**：「看起来核心在于“做”，其实本质是在“想”」
