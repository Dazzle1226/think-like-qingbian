# 那些不婚不育的人们，老了怎么办？

**一句话**：有孩子的老人多数也过得不好，因为老了对孩子只剩拖累；让人善待你的关键不是有没有孩子，而是你有没有价值、有没有钱。有资产就能用商业服务的「胡萝卜加大棒」买到比子女更好的照顾。

**论证链**
1. 作者观察上一代、上上代老人：几乎都有孩子，却多半被子女推来推去、被嫌弃，或在养老院里很少被探望。
2. 老年的惨在于体力、精力下降，又跟不上新东西。对孩子没价值、只有拖累时，赡养久了孩子会盼你早死。
3. 反例是富豪的孩子普遍孝顺：你还有用时，别人对你好是一种投资，人性中真善美的一面会被利益推着展露出来。
4. 护工差是因为收入低、干不干都一样。如果护工收入高、门槛高、差评就换人，服务自然好。商业激励比「有孩子在所以不敢造次」的震慑更有力。
5. 不婚不育省下的钱和精力，应该攒成资产。比如一套房子，可以反向抵押换取月供，购买顶级养老服务。
6. 把房子提前过户给孩子，会遇到成本后置：几年后孩子觉得房子本来就是自己的，开始「白白尽孝」。
7. 未来老人多、孩子少，养老是巨大的蛋糕，商业机构会提供更好的服务来赚这份钱。

**可复用的模型**
- **价值决定待遇**：对别人有用时，别人对你的好是投资；没有用时只剩义务。
- **激励比震慑可靠**：高薪 + 可替换 + 评价机制，胜过靠亲属监督。
- **资产留在自己手里**：提前给出去，就触发成本后置。
- **非线性看未来市场**：今天烂的服务，在需求暴涨后会被商业填平。

**可调用的场景**：担心不婚不育老了没人管时；要不要把房子提前过户给孩子；规划养老资金时。

**原文锚句**：「人心就像太阳，不可直视，只有利益博弈永恒。」

**使用边界**（整理者注，不是作者观点）
- 「以房养老在中国会普及」「几十年后养老服务会变好」是作者的预测；反向抵押在国内的实际推行情况需核实。
- 对老年人处境的描述来自作者个人观察，不是统计。
