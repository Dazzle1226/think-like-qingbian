# 人和人的相处，本质在于筛选，而不是迎合

**一句话**：在信息、资源、机会过剩的时代，缺的是深度的交流、绑定与合作；所以与人相处的关键是筛选同频的人，而不是迎合所有人。对外表达是为了让同频的人找到你，筛选不严会让整个池子都不舒服。

**论证链**
1. 引子：有读者报名付费任务被拒，留言希望作者批评助理。作者回应：拒绝是他授意的，目的就是只筛选同频的人。
2. 「多个朋友多条路」的人情世故，适用于陌生人交流少的旧时代。
3. 现在持续做事的人不缺朋友、信息、资源、机会，缺的是深度。信息只是在面前流过，就会出现「机会都见过、一个没抓住」的情况。
4. 资源有限时应面面俱到；资源无限时，精力越摊薄越完蛋。
5. 向外辐射影响力，不是为了被所有人认同，而是让同频的人找到你。不认同的人直接走就好。
6. 每次表达和服务筛选都留下同频的人，池子越来越大；放进不同频的人，骂战和麻烦增加，大家都不舒服。平台为了流量放宽界限，就会导致价值观泛化，老用户离开。
7. 犹太人通过共同的宗教活动形成同频的共享时空，在其中产生互助和商业机会。

**可复用的模型**
- **筛选 > 迎合**：资源过剩时，深度比广度重要。
- **同频池**：表达扩圈 + 严格筛选 = 持续变大的同频群体。
- **泛化稀释**：为了规模放宽门槛，会赶走核心人群。

**可调用的场景**：想讨好所有人、怕得罪人时；做社群、做内容决定受众时；面对不认同你的人时。

**原文锚句**：「我们只筛选同频的人」

**使用边界**（整理者注，不是作者观点）
- 引子涉及作者付费服务拒绝用户的事，属于业务背景，不作为推广引用。
- 关于犹太人宗教活动功能的说法是作者的解读，需核实。
