# 雷军不是中国的乔布斯，而是中国的马斯克

**一句话**：作者认为，雷军和马斯克性格、行事风格迥异，做事的内核却一致：第一性原理。把每个环节拆开弄懂、论证必要性，去掉不必要的东西，走最短的路径。所以他们进入哪个行业，就能把价格打下来、改变那个行业的玩法。所谓「水很深」，常常只是没人去刨根问底。

**论证链**
1. 雷军短暂成为首富，作者猜他的团队会淡化这个身份，因为在国内这对形象并不正面。
2. 很多人从产品角度称他为「雷布斯」，作者更愿意类比马斯克：一个张扬、一个内敛，一个从 0 到 1、一个进入成熟市场，只是不同的土壤结出了不同的果子。
3. 两人的共同内核是第一性原理：每个环节都去弄懂、优化、论证必要性，而不是「同行都这样做我也这样做」。所以从手机到电视到车，都能做到品质不差、价格更低。
4. 任何事情都能拆成说得清楚的单元，「水很深」往往是被人为打了哑谜、制造了模糊空间。刨根问底以后，会发现没那么复杂，谁的利益都可以动，只是方式温和或激进的区别。
5. 这种企业家的上限很高，能改变行业的玩法。作者把王兴也归入这一类，反例是在商业决策里夹带个人情绪的企业家。
6. 作者认为，中国不是没有马斯克，只是他们无法在这片土壤里进化成那种形态；再往前走一步，形象就可能崩塌。

**可复用的模型**
- **第一性原理**：拆到最小单元，逐项论证必要性。
- **「水很深」是人为制造的模糊**：刨根问底就能破除。
- **最短路径**：去掉一切不必要的环节。
- **商业决策不夹带情绪**。

**可调用的场景**：分析一个行业为什么贵、哪里可以优化；自己做事时检查有哪些「大家都这样做」的环节；判断企业家的上限。

**原文锚句**：「任何事情，都可以拆解成“说得清楚”的单元」

**使用边界**（整理者注）
- 对多位企业家的褒贬是作者的个人评价，不要当作事实引用。
- 和《雷军为什么不可模仿？》（流量和规模）是同一主题的不同角度。
