# 考研的性价比

**一句话**：万事看性价比。学历的价值来自它的筛选作用和稀缺性，如今多数研究生不再稀缺，比较对象也不该是「没学历的人」，而是工作了四年的人；劳动报酬只跟供需有关，选择要看社会当下实际需要什么人。

**论证链**
1. 引子：读者的孩子考研失利但拿到券商 offer，问该工作还是二战。
2. 父母那代大学生稀缺，考上就能证明能力，性价比高。如今要看是什么学校、什么专业。
3. 非强专业性、非冷门的专业，即便是名校研究生，也只有公务员、事业单位还看重；需要真实产出的地方不会为学历买单。
4. 我们学的大部分东西没什么用。基础需要，但不值得占用人生四分之一、五分之一的时间。
5. 二战加读研，出来是四年后。要跟工作四年的人比：作者公司里学校一般但会钻研的人，一两年就升主管。
6. 「人人都读研，我不读就更找不到工作」是错的：当一个筛子筛不出差别时，被取代的是筛子。比如新加坡很多人能上大学却直接工作。
7. 劳动报酬只取决于供需。想不明白这点的人，和想不明白房价为什么会跌的人往往是同一批。

**可复用的模型**
- **比较要对齐时间**：读书 N 年要跟工作 N 年的人比。
- **筛子会被替换**：当一个指标失去区分度，社会会换别的维度判断人。
- **报酬看供需**：问社会缺什么人，而不是学历够不够高。
- **多想一层**：表象易变，要看背后的原因。

**可调用的场景**：在考研、二战、读博与工作之间纠结时；担心学历通胀时；帮孩子做升学决策时。

**原文锚句**：「凡事多想一层，因为表象易变。」

**使用边界**（整理者注，不是作者观点）
- 作者对公务员、事业单位「浑水摸鱼」的评价是个人观点。
- 专业性强的领域（医学、科研等）学历仍有硬门槛，作者原文也排除了这类专业。
