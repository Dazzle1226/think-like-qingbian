# 高三女生百日誓师演讲为何被网暴？

**一句话**：高考能改变一小部分人的命运，但不值得所有人卷十几年；问题不在激励，而在高估了它能改变的人数和程度。真实社会里，卷是有用的，但别去「卷不赢就是人生 loser」的地方卷，更重要的是选对第 0 步。

**论证链**
1. 网暴要有界限：辱骂、攻击长相是丑陋的；但基于社会经历提出不同看法是合理的。不是只有鲜花和掌声才算正能量，只剩一种声音才最可怕。
2. 高考像一个只有第一名拿大奖的游戏：它确实能改变命运，但只对极少数人。教育分流从中学就开始，最终靠高考获得显著优势的人占比极小。
3. 普通人上了大学也做普通工作，晋升几率未必比泥瓦匠当上项目经理大。打鸡血让多数人最后失望，甚至变成反对者和网暴者。
4. 区别在于有没有平行替代：做副业做不好可以换别的，高考却被宣传为没有替代，「考不好就去要饭」。
5. 作者提倡卷，因为卷赢的人有马太效应；但反对去「卷不赢就是人生失败者」的地方，那里像邪教。输了只是这个游戏的输家，可以开另一个游戏。
6. 真实社会更重要的是 0 到 1：选择进入哪个领域，比在一个领域里拼命更重要。努力没用，往往是因为缺乏筛选第 0 步的能力。

**可复用的模型**
- **比例问题**：一条路能改变命运，要看它能改变多少人。
- **有没有平行替代**：把一件事当作唯一出路，是压力和扭曲的来源。
- **第 0 步 > 第 1 步**：选赛道的视野，比在赛道上的努力更重要。
- **换游戏**：没有哪里是输了就是人生输家。

**可调用的场景**：对高考、考研、考公过度焦虑时；觉得自己拼命努力却没回报时；讨论教育路径和孩子的选择时。

**原文锚句**：「第0步的重要性，大于第1步。」

**使用边界**（整理者注，不是作者观点）
- 关于衡水中学、咪蒙、Yuga 游戏奖金等事例，需核实细节。
- 「高考宣传影响生育率乃至国运」是作者的推论。
