# 你以为你在做事，其实你在卷人

**一句话**：一件事能拿到多少回报，取决于供需和你在供给方中的排名，而不是你做了多少事。卡在平台期，往往是因为大家在同步进步；熬到别人放弃、排名靠前了，结果才会出来，然后马太效应接手。

**论证链**
1. 就算你是在创造增量、做大蛋糕，也还是在和别人卷。纺织机提高了效率，没用纺织机的人单位时间的价值就降低了。
2. 生活的绝对水平提高了，相对水平变弱带来的不满依然存在，最低标准也跟着水涨船高。
3. 回报来自供需关系：只有你一个人做，做得烂也是大师；能赚钱的地方，自然会有人涌进来，原地踏步的人就分不到了。
4. 常见的轨迹是：一开始进步很快（从 0 到 60 分谁都快），然后卡住，没有反馈，失去兴趣，放弃。
5. 卡住的原因是大家同步进步，你的排名没有变。反馈只给排名靠前的人。
6. 靠什么突破？有人撑不住走了，新人从 0 开始排，你的排名相对靠前了，再加上运气的概率慢慢起作用，某一天结果就来了。成为专家，往往是因为排到前面以后，得到了只有你才能接触的机会、人和问题。

**可复用的模型**
- **回报取决于排名，不取决于付出**。
- **平台期是因为大家同步进步**：没有反馈，不代表你没有进步。
- **熬出来**：靠的是别人放弃，而不是自己突然变强。
- **先排到前面，再成为专家**：之后的事交给马太效应。

**可调用的场景**：做一件事卡在平台期，想放弃；觉得「我这么努力，社会应该回报我」；判断一个赛道值不值得长期坚持。

**原文锚句**：「任何做事，本质上都是在卷人」

**使用边界**（整理者注）
- 前提是这件事「只要排名够高，长期就确定有高收益」。如果赛道本身在萎缩，熬下去未必有用，要先判断赛道。
