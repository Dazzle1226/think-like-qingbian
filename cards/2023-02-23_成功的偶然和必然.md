# 成功的偶然和必然

**一句话**：成功有偶然，但运气只在「池子」里的人之间分配——那些做得很好、积累很久、在冷静期就开始冒风险的人。偶尔努力一下没成就怪运气，是因为你根本没进池子。

**论证链**
1. 没做过事的人容易低估事情的内部结构，说「淘宝几万块一套」「实习生十几天就能做出来」，是因为无知。
2. 偶然：成功者自己也不知道哪次能成。必然：成功只光顾一直在做的人，失败一次就停的人没有后续。所以做得越多，成功概率越大。
3. 成功不是随机挑一个，而是从做得好、积累多的人里挑。先进入池子，才轮得到谈运气。
4. 好产品需要时间。市场火热时才组队开工，等做出来领先者早就补齐了，所谓创新点子别人可能已经做了很久。
5. 例子：Blur 做了一年多才被大众知道，创始人之前就有成功产品；带货主播换平台前就卖得很好，平台只是影响力的放大器。

**可复用的模型**
- **进池子才谈运气**：先问自己有没有满足「做得好 + 积累久 + 早冒险」。
- **冷静期起步**：在没人关注的时候开始做，火热期才有东西拿得出手。
- **平台是放大器**：新平台放大的是你已有的能力，不会凭空创造。
- **多次尝试**：成功概率随尝试次数上升。

**可调用的场景**：觉得别人成功只是运气好时；想趁风口快速组队做项目时；一次失败后想放弃时。

**原文锚句**：「成功是从做得很好的人、积累了很多的人里挑一个，不是随机挑一个。」

**使用边界**（整理者注，不是作者观点）
- 周鸿祎的话、Blur 创始人背景等是作者转述，引用前需核实。
