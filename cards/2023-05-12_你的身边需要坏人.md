# 你的身边需要坏人

**一句话**：智慧无法凭空生成，遇到坏人是成熟的必经之路；文明进步靠的是先假设人性会作恶、再用规则限制，而不是相信人性美好。坏人越早出现、越多，漏洞暴露得越早，你和系统就越反脆弱。

**论证链**
1. 能量弱时，坏人坏得明显（嘲讽、刁难）；能量强时，坏人以好人的面目出现。所以人只能一步步往上走，否则接不住大场面：富二代直接接班、底层中彩票拆迁，多半出事。
2. 作者不投第一次创业的团队：第一次不可能见识所有的坑和分钱时的人性，规则一定不够精确，一定有纠纷。经历过才能成熟。
3. 普通人身边没坏人，就永远是小白；总相信人性和道德约束的人，余生必然会在毫无防备中受到大打击。
4. 文明进步是用规则限制人性作恶的过程。你不去抢有钱人，真实原因是代价太大。
5. 所有规则都是先有坏人才完善的，具有滞后性；合伙要签那么多文件，正是因为不能假设大家都是好人。同一批人在不同环境里表现不同，橘与枳是土壤的问题。
6. 黄牛和黑客越多越好：早期小漏洞被撸，平台尽早补齐，避免后期的大损失，这叫反脆弱。人生同理，每个台阶上都被各种坏人试过一遍还能登顶，才不会轻易被拉下来。

**可复用的模型**
- **先假设最坏，再设计规则**：人在作恶代价大时才表现为好人。
- **规则滞后**：规则是被坏人推动完善的。
- **早暴露 = 反脆弱**：小损失早出现，避免大损失。
- **逐级历练**：每个层级的坏人不同，跳级会接不住。

**可调用的场景**：合伙创业、签协议时；被人坑了、觉得世界不公时；评估一个缺乏历练的人能否担大任时。

**原文锚句**：「文明靠的是规则，而不是人性」
