# 好人和坏人

**一句话**：给人贴好人或坏人的标签，只是给自己的粗暴行动指南；人是立体的，成年人该建立立体模型，判断和对方交互能否获益。作者不喜欢「好人」这个形象，喜欢有预期、有规则、可控的真实的人。

**论证链**
1. 贴标签不是在描述对方，而是在指导自己：好人安全，坏人警惕。孩子这么做正常，成年人还这么做就幼稚了。
2. 好坏取决于立场：杀手在受害者家属眼里是坏人，在女儿眼里是好人。
3. 一个人被大多数人认为是好人，要么离大家足够远、细节不被知道，要么身上枷锁足够多。
4. 人们喜欢跟好人相处，是因为好人怕坏口碑、容易被道德绑架，跟他们相处容易占便宜。
5. 举例：不赌不嫖、做善事却不顾家不挣钱的男人；违背公序良俗却捐建希望小学的富豪——单一行为判断不了好坏。
6. 作者中学时一个师德有争议但教学极强的老师，让他受益很多；规矩却教不明白的老师没用。
7. 真实的人人性相似，所以有预期、有规则、可控：知道你图什么，只要你符合期待、守规则，就可以合作；有筹码多拿，没筹码耐心少拿。

**可复用的模型**
- **标签即行动指南**：问自己贴这个标签是为了做什么决定。
- **立体模型**：评价人看具体切片和交互收益，不看整体道德评分。
- **好人 = 枷锁多**：被普遍称好的人，往往是受约束多、易被绑架的人。
- **真实的人可预期**：知道对方图什么，比相信对方是好人更可靠。

**可调用的场景**：纠结要不要和某个「人品有争议」的人合作时；被人说成「坏人」或用道德绑架时；选老师、选老板、选合作者时。

**原文锚句**：「我从不喜欢好人，我喜欢真实的人。」

**使用边界**（整理者注，不是作者观点）
- 文中提到的微博「煮肘」等真实人物事件需核实。
- 作者的立场是从交互收益出发评价人；在涉及违法或伤害他人的情况下，不能用这条去合理化。
