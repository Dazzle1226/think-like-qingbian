# 烂尾楼并非绝对的坏事

**一句话**：好制度都是在极端坏事发生后打补丁得来的，烂尾楼对当事人是灾难，对社会整体却会推动制度完善；香港也曾大规模烂尾，后来通过地价付清、银行担责、预售款专户监管等补丁基本消除了烂尾。我们学了一半，剩下的照抄作业即可。

**论证链**
1. 法律总是滞后：人无法预想所有事，只能事后打补丁。飞行安全、手术规范，背后都是无数生命的代价。
2. 烂尾本质由预售制度导致：只有没盖完的房子才会烂尾，盖完了最多跌价。
3. 预售源于香港的「卖楼花」，本意是让开发商快速回款、减少因缺钱烂尾。
4. 但人性贪婪：预售款到手后，一部分拿去继续拿地，系统性风险一来就处处烂尾。香港当年按比例比今天还严重。
5. 香港的补丁：预售前必须付清地价；必须证明有能力支付剩余建筑费，贷款银行要出承诺书、烂尾由银行负责；预售款进专户，由律师行按进度审核解锁；房子交付前业主不用还贷，烂尾后也不用再还按揭。
6. 「盖完才能卖」不是正确方向，预售反而能减少烂尾，问题在于配套不完善。
7. 学一半可能是没经验，人不撞南墙不回头；买到烂尾楼的人是直接受害者，其他人也会因印钱解决问题而间接受损。
8. 发达国家走过的路就是我们的未来信息，看得到的人能提前规避甚至抓住机会。

**可复用的模型**
- **制度补丁**：规则在事故后完善，规则越完善，意外越少。
- **风险承担者应有风控能力**：让有审核能力的银行担责，而不是老百姓。
- **资金专户 + 按进度解锁**：防止挪用的通用机制。
- **抄作业**：别人已验证的方案，直接用。

**可调用的场景**：买期房时评估风险；设计防挪用的资金管理机制时；理解制度为什么滞后时。

**原文锚句**：「所有好的制度，都是以之前发生了极端不好的事情作为前提的」

**使用边界**（整理者注，不是作者观点）
- 香港预售制度细节（承诺书、律师行监管、业主不还贷等）是作者的描述，需对照香港相关规定核实。
